왼쪽 · 개념

테마 하나는 CSS 변수 한 벌입니다. 색·서체·모서리·그림자를 전부 :root 안으로 모읍니다.

  • — 토큰은 의미를 정한다. 색상값을 직접 쓰지 않는다
  • — base.css 는 토큰으로 조판한다
  • — 테마는 변수만 바꾼다

오른쪽 · 실물

:root {
  --bg: #fff;
  --text-1: #0c0d10;
  --accent: #3b6cff;
  --radius: 18px;
}
.card {
  background: var(--bg);
  color: var(--text-1);
  border-radius: var(--radius);
}
