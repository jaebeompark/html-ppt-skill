# hermes-cyber-terminal

Black ground (`#0a0c10`) with terminal chrome, scanlines, mint-green glow headlines, and JetBrains Mono throughout. The voice is an honest technical review.

**Visual traits:** a 56px cyber grid with CRT vignette and translucent scanline overlay, window traffic-light chrome, `$ prompt` command-line headlines, mint-green `#7ed3a4` text-shadow glow, monospace everywhere, stroke-only bar charts, a blinking cursor, and amber/green/red tier tags.

**Use when:** reviewing a developer tool, CLI, or agent with benchmark data, traces and diffs; you want the visual register of a technical reviewer being straight with the audience; long traces and long code hold up here.

**Path:** `templates/full-decks/hermes-cyber-terminal/index.html`
