03 / 08
● COMPARE

Notion vs Obsidian · AI 친화도

NOTION

데이터베이스가 기본

구조화된 작업과 팀 협업에는 맞습니다. 다만 —
• AI 는 API 를 거쳐야 해서 실시간 전문을 못 봅니다
• 중첩 블록 구조가 복잡해 토큰 비용이 큽니다
• 로컬에 남지 않아 장기 기억으로 쓰기 어렵습니다

OBSIDIAN

순수 Markdown + 양방향 링크

태생적으로 AI 에 잘 맞습니다 —
• 전부 그냥 파일이라 Claude 가 바로 읽습니다
• 양방향 링크가 곧 그래프라 엔티티 추출이 거의 공짜입니다
• 오프라인에서 되고 git·diff·되돌리기가 됩니다

💡 핵심: AI 에게 필요한 건 더 똑똑한 데이터베이스가 아니라, 스스로 읽을 수 있는 파일 시스템입니다.

● SETUP · 4 STEPS

0 에서 "AI 가 노트를 쓰는" 순간까지

1

Obsidian 설치 + Local REST API 플러그인 켜기

커뮤니티 플러그인이라 체크 한 번이면 됩니다. 외부 프로세스가 vault 를 읽고 쓸 수 있게 해 줍니다.

2

Claude Desktop + obsidian-mcp 서버 연결

MCP 는 설정 파일 하나로 붙습니다. token 자리에 vault 의 api key 를 넣으세요.

3

obsidian-skills 다섯 개 설치

markdown / bases / canvas / cli / defuddle — Claude 가 Obsidian 을 제대로 다루는 법을 알게 됩니다.

4

Claude 에게 한 번 정리를 맡기기

"최근 노트 10편에서 겹치는 개념을 합쳐 새 MOC 를 만들어 줘" — 90초면 결과가 나옵니다.

05 / 08
● MCP CONFIG

claude_desktop_config.json

// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-obsidian"],
      "env": {
        "OBSIDIAN_API_KEY": "xxxxxxxxxxxxxxxx",
        "OBSIDIAN_HOST": "http://127.0.0.1:27123"
      }
    }
  }
}

Claude Desktop 을 다시 켜고 /mcp 를 입력하면 obsidian 이 연결된 게 보입니다.
