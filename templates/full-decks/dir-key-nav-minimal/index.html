Minimal Setup

YAML 네 줄이면
시작합니다.

memory:
  root: ~/.llm-wiki
  format: markdown
  retrieval: hybrid  # embedding + bm25

시간이 지날수록 자라는 두 번째 뇌가 생겼습니다. 대화할 때마다 읽히고, 갱신됩니다.
