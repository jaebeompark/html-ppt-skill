# dir-key-nav-minimal

8 slides, each on its own solid mono background (indigo / cream / crimson / emerald / slate / violet / white / charcoal). Eight `t-*` theme classes, one background per slide, arrow keys to move — minimal editorial pacing.

**Visual traits:** a separate background colour and single accent per slide, huge 160px headlines with no supporting art, a 4px stubby accent-line divider, arrow-prefixed mono list, `← →` keyboard hint bottom-left and page label bottom-right, generous breathing negative space, JetBrains Mono for numbers / code / key hints, and a `.dk-accent` colour that belongs to each background.

**Use when:** you have something to say and not much to show; keynote-style minimalist talks; one idea per slide; public talks and launches.

**Path:** `templates/full-decks/dir-key-nav-minimal/index.html`
