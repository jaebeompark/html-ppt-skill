# graphify-dark-graph

Deep-night ground with a force-directed knowledge-graph overlay and warm glass-morphism cards.

**Visual traits:** a `#06060c → #0e1020` diagonal gradient, three 400–520px blurred orbs drifting slowly, an SVG force-directed graph behind the cover, rainbow-shift gradient headlines, a JetBrains Mono `.cmd-glow` command line, glass cards with a top highlight and subtle inner shadow, and a warm accent set — amber `#e8a87c`, mint `#7ed3a4`, mist-blue `#7eb8da`, lilac `#b8a4d6`.

**Use when:** introducing a developer tool, a command-line product, or a knowledge-graph / data-visualisation project; you want the live demo to feel AI-native and technical but still warm.

**Path:** `templates/full-decks/graphify-dark-graph/index.html`
