Feature Map

도구 하나가 네 가지 일을

📂

Folder Ingest

어떤 경로든 재귀로 훑습니다. md / pdf / 코드 / 이미지

🧠

Entity Extract

LLM 으로 개념·인물·사건·관계를 뽑습니다

🕸️

Force Graph

D3 force layout. 클릭하면 원문으로 갑니다

🔍

Audit Trail

모든 엣지를 source span 까지 되짚을 수 있습니다

"또 하나의 RAG" 가 아닙니다. 검색 결과를 그림으로 그려서, 정보가 어떻게 생겼는지 한눈에 보이게 하는 것입니다.

04 / 08

One command

0 에서 그래프까지 90초쯤

$ graphify ~/notes --out ./graph

# graphify.config.yaml
ingest:
  paths: [~/notes, ~/code/docs]
  include: ["*.md", "*.pdf", "*.py"]

extract:
  model: claude-opus-4-6
  schema: [concept, person, event, relation]

render:
  engine: d3-force
  audit: true     # 모든 엣지에 source span 을 붙임
