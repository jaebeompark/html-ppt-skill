# presenter-reveal · 한국어 발표자 모드 템플릿

**대본을 보면서 발표하는** 한국어 기술 공유용 full-deck 템플릿입니다.
`presenter-reveal`(중국어)의 한국어 대응판이고, 한글 조판과 한국 사내 발표의
흐름에 맞춰 다시 짰습니다.

## 사용 시나리오

- 사내 기술 공유 (20~40분)
- 팀 회고 발표, 프로젝트 결과 공유
- 컨퍼런스 발표 리허설
- **대본대로 읽으면 안 되지만, 안 보고 하기도 불안한** 모든 발표

## 시작하기

```bash
cp -r templates/full-decks/presenter-reveal examples/my-talk
open examples/my-talk/index.html
```

발표장에서는 `S`를 눌러 발표자 창을 띄우고, 그 창을 노트북 화면에 두고
덱은 빔프로젝터로 넘깁니다. 두 창은 자동으로 동기화됩니다.

## 키보드

| 키 | 동작 |
|---|---|
| `S` | 발표자 창 열기 (현재 / 다음 / 발표 대본 / 타이머) |
| `←` `→` / `↑` `↓` | 페이지 이동 (두 창 동기화) |
| `T` | 테마 순환 — tokyo-night · catppuccin-mocha · dracula · nord · corporate-clean |
| `F` | 전체화면 |
| `O` | 전체 슬라이드 개요 |
| `N` | 하단 노트 서랍 |
| `R` | 타이머 초기화 (발표자 창) |
| `Esc` | 오버레이 닫기 |

## 8장 구성

내용은 예시입니다. 흐름만 남기고 내용을 갈아끼우면 대부분의 사내 발표에 맞습니다.

| # | 슬라이드 | 역할 | 배정 |
|---|---|---|---|
| 1 | 표지 | 주제 한 줄 + 발표자 | 1분 |
| 2 | 목차 | 네 부분 + 시간 배분 | 1분 |
| 3 | 문제 | 겉으로 드러난 것 ↔ 실제로 아팠던 것 | 4분 |
| 4 | 오판 | 잘못 짚었던 시도 세 가지 | 6분 |
| 5 | 측정 | 실제로 한 것 (코드 한 조각) | 8분 |
| 6 | 결과 | 큰 숫자 하나 + 카운트업 | 3분 |
| 7 | 배운 점 | 주제를 벗어나도 남는 것 세 가지 | 3분 |
| 8 | 마무리 | 한 문장 + Q&A | 3분 |

각 `<aside class="notes">` 끝에 `[리허설: …]` 줄이 있습니다. 시간 배분과
"여기서 서두르지 말 것" 같은 진행 메모라, 실제 발표문을 쓸 때 같이 갈아끼우세요.

## 발표 대본 쓰는 법

이 템플릿의 예시 대본은 세 가지를 지킵니다.

1. **읽는 글이 아니라 신호** — 핵심어를 `<strong>`으로 굵게 두고, 전환 문장은
   문단을 나눕니다. 발표자 창에서 눈이 한 번에 잡습니다.
2. **한 장에 150~300자** — 2~3분 분량입니다. 넘어가면 슬라이드를 쪼개세요.
3. **입말로** — "따라서"보다 "그래서", "해당 방안"보다 "이 방법". 글말로 쓰면
   읽는 티가 납니다.

## 한글 조판

`style.css`가 한국어 발표에서 실제로 문제가 되는 두 가지를 처리합니다.

- **`word-break: keep-all`** — 브라우저 기본값은 한글을 아무 글자에서나 끊습니다.
  큰 제목에서 "발표자료가"가 "발표자 / 료가"로 갈리면 읽는 리듬이 무너집니다.
  어절 단위로 넘어가게 했습니다.
- **여유 있는 행간** — 한글은 라틴보다 글자가 빽빽해서 같은 `line-height`면
  답답해 보입니다. 제목 1.22, 본문 1.75로 잡았습니다.

코드 블록은 `word-break: normal`로 되돌립니다. 코드까지 어절 단위로 끊으면
오히려 깨집니다.

## 폰트

산세리프는 [Pretendard](https://github.com/orioncactus/pretendard)입니다.
라틴과 한글을 한 벌이 덮어서, `12분 → 3분` 같은 숫자·기호 혼용 줄에서
자간과 베이스라인이 어긋나지 않습니다. `assets/fonts.css`가 이미 불러옵니다.

`T`로 테마를 바꿔도 폰트는 유지됩니다. 세리프 테마로 바꾸면 한글은
`Noto Serif KR`(명조)로 전환됩니다.
