# card-news-editorial

White-ground magazine editorial: strong emphasis blocks and macaron soft-card grouping. Works both as a card-news image set and as a landscape deck.

**Visual traits:** pure white background, a 10-colour rainbow bar across the top, huge 80–110px headlines on slightly negative tracking, gradient brand text (purple → blue → green → orange → pink), macaron soft cards (soft-purple / pink / blue / green / orange), pill tags with a dot, black-on-white `.focus` emphasis boxes, and a hero quote box with a light shadow.

**Use when:** the content is text-dense with a lot to emphasise and the reader needs to catch the key words at a glance; you want one source that serves both a social card set and a talk.

**Path:** `templates/full-decks/card-news-editorial/index.html`
