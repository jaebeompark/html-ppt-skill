# knowledge-arch-blueprint

Cream paper (`#F0EAE0`), a single rust accent (`#B5392A`), hard black-bordered cards and dashed feedback-loop arrows. It reads like an architectural blueprint rather than a slide.

**Visual traits:** warm off-white paper ground, a faint 48px grid for the blueprint feel, hard 2px black card borders, pipeline step-boxes in a row with one hero box raised, a rust insight callout on the right, 2.5–4px letter-spaced kickers, SVG dashed feedback loops with arrowheads, Playfair serif for large figures. No gradients, no soft shadows — deliberately restrained.

**Use when:** system architecture, data flow, process breakdowns; you want the deck to look like a serious technical white paper rather than a marketing post; you need something printable that can be screenshotted straight into a README.

**Path:** `templates/full-decks/knowledge-arch-blueprint/index.html`
