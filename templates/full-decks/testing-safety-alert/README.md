# testing-safety-alert

White ground with red-and-amber alert colour, hazard-striped edges, and large red strike-throughs and pills. The tone is deliberately pitched at "incident report", not "product update".

**Visual traits:** a 45° red-and-black hazard stripe along the top and a lighter one along the bottom, red strike-through negation headlines, L1/L2/L3 tier cards (green / amber / red), an alert box with a circular status light, a policy-YAML dark code block with a red left border and highlighted `bad` keywords, a red/green checkbox checklist, and a quarterly incident bar chart.

**Use when:** safety, risk, incident post-mortems, red-team results, pre-launch AI review, policy-as-code — anywhere the audience needs to feel that this is serious and should not be skimmed.

**Path:** `templates/full-decks/testing-safety-alert/index.html`
