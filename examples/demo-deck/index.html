How · 핵심 발상

"어떻게 보일지"를 :root 안으로

개념

색·서체·모서리·그림자 같은 시각 속성을 전부 의미를 가진 변수로 바꿉니다.

  • --text-1 / --text-2 / --text-3
  • --surface / --surface-2
  • --accent / --accent-2 / --accent-3
  • --radius / --shadow / --grad

실물

/* assets/themes/aurora.css */
:root {
  --bg: #06091c;
  --text-1: #e8f0ff;
  --accent: #5ef2c6;
  --accent-2: #7aa2ff;
  --accent-3: #c984ff;
  --radius: 20px;
}

— aurora 테마 전체가 이만큼입니다.

how
핵심은 base.css 가 변수 이름만 안다는 겁니다. 색상값은 모릅니다. 테마를 바꾼다는 건 변수 한 벌을 바꾸는 일이에요.
